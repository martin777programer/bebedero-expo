01 / PRESENTACIÓN

De una necesidad a una solución.

Una propuesta tecnológica desarrollada por estudiantes de Informática.

¿En qué consiste nuestro proyecto?

Nuestro proyecto consiste en diseñar y construir un bebedero que incorpore componentes electrónicos para controlar un mecanismo mediante un sensor ultrasónico, una placa Arduino y un servomotor.

El sensor ultrasónico permite medir la distancia hasta un objeto o una persona que se encuentre frente al dispositivo. Arduino recibe esa información, la procesa y controla el movimiento del servomotor según las instrucciones del programa.

La estructura también contempla el uso de nailon como parte del mecanismo del prototipo. Además, el proyecto contará con un interruptor para seleccionar la opción de agua caliente.

La finalidad es aplicar los conocimientos adquiridos en la orientación Informática, integrando programación, electrónica, construcción y trabajo en equipo.

03 / FUNCIONAMIENTO

¿Cómo funciona?

El sistema combina medición de distancia, procesamiento electrónico y movimiento mecánico.

01

Detección de distancia

El sensor ultrasónico emite ondas sonoras y mide el tiempo que tarda en regresar el eco. Con esa información calcula la distancia hasta un objeto.

02

Procesamiento con Arduino

Arduino recibe la medición del sensor y la compara con los valores establecidos en el programa. De esta manera determina qué acción debe ejecutar el sistema.

03

Movimiento del servomotor

Cuando se cumple la condición programada, Arduino envía una señal de control al servomotor para mover el mecanismo previsto en el diseño del bebedero.

04

Selección de agua caliente

El interruptor permitirá seleccionar el modo de agua caliente. El sistema concreto de suministro dependerá de cómo se construya el prototipo.

Importante: El sensor ultrasónico mide distancia, no temperatura. El interruptor selecciona un modo de funcionamiento, pero no calienta el agua por sí mismo.

04 / COMPONENTES

Las partes del proyecto.

Estos son los principales elementos previstos para construir el prototipo.

COMPONENTE 01

Sensor ultrasónico

Es un dispositivo electrónico que mide distancias mediante ondas sonoras. Sus mediciones permiten detectar la presencia de un objeto dentro del rango de detección.

COMPONENTE 02

Servomotor

Es un motor que permite controlar el movimiento angular de un mecanismo. En el proyecto se utilizará para accionar la parte mecánica diseñada.

COMPONENTE 03

Arduino

Es la placa electrónica programable que recibe los datos del sensor, ejecuta las instrucciones del programa y controla el servomotor.

COMPONENTE 04

Nailon

Se utilizará como parte del mecanismo o de la estructura del prototipo, según las necesidades del armado.

COMPONENTE 05

Interruptor

Permitirá seleccionar el modo de agua caliente mediante una acción manual del usuario. Su conexión deberá adecuarse al circuito definitivo.

05 / MODOS DE USO

Agua fría y caliente.

El proyecto contempla dos opciones de utilización del bebedero.

❄

MODO 01

Agua fría

Es la opción de funcionamiento normal del bebedero. El sensor ultrasónico realizará la medición de distancia y Arduino controlará el servomotor de acuerdo con la programación.

♨

MODO 02

Agua caliente

El usuario podrá seleccionar esta opción mediante un interruptor. El sistema permitirá utilizar el modo de agua caliente según el mecanismo definido para el proyecto.

El sistema de agua caliente deberá contar con protección contra quemaduras y una instalación eléctrica segura.
